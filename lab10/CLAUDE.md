NCBI에서 서열을 받을 때
wget과 NCBI E-utilities를 사용한다.
URL에 &와 같은 특수문자가 포함되어 있으므로 주소 전체를 반드시 큰따옴표로 감싼다.
여러 서열을 반복해서 다운로드할 때는 요청 사이에 sleep 1을 넣는다.
유전자 하나의 서열을 받을 때는 검색 조건에 [SLEN]을 사용하여 길이를 제한한다.
다운로드한 파일마다 GenBank 파일의 VERSION과 ORGANISM을 확인하고 사용자에게 알려 준다.
FASTA 파일마다 서열 개수와 길이를 확인한다.
요청한 생물 종과 실제 ORGANISM의 학명이 일치하는지 확인한다.
검색 결과가 없으면 검색어를 임의로 바꾸거나 다른 종의 서열을 가져오지 말고 먼저 사용자에게 알린다.
다운로드한 파일이 비어 있거나 예상한 형식과 다르면 정상적으로 받았다고 보고하지 않는다.
