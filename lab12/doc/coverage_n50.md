# 커버리지와 N50의 관계

## 1. 예상 (조립 전에 작성)

- 원본 커버리지: 전체 염기 수 3,744,000 bp (12,480 쌍 × 150 bp × 2) ÷ 추정 유전체 크기 61,920 bp ≈ **60x**
- 원본 조립 결과: contig 12개, 전체 180,912 bp, N50 = **58,878 bp**

**예상:** 커버리지와 N50은 같은 방향으로 움직인다(양의 관계).
커버리지가 낮아지면 유전체의 어떤 위치는 read가 거의 없거나 아예 없는 구간(gap)이 생기고,
read끼리 겹치는 부분이 줄어들어 assembler가 서열을 이어 붙이지 못하는 곳이 많아진다.
그러면 contig가 더 잘게 끊어지므로 contig 수는 늘고 N50은 줄어들 것이다.

단, 커버리지가 충분히 높은 구간(대략 30x 이상)에서는 이미 거의 모든 위치를 여러 번 읽었기 때문에
read를 절반으로 줄여도(60x → 30x) N50이 크게 떨어지지 않을 수도 있다.
N50이 급격히 무너지는 것은 커버리지가 10~15x 이하로 내려갈 때일 것이라고 예상한다.

## 2. 실험 방법

```bash
# read 쌍의 50% 만 무작위로 뽑는다. R1 과 R2 에 같은 seed(-s 11)를 써야 짝이 유지된다.
seqkit sample -p 0.5 -s 11 data/R1.fastq -o data/R1.half.fastq
seqkit sample -p 0.5 -s 11 data/R2.fastq -o data/R2.half.fastq

# 1차 시도: 원본과 같은 명령 → 실패 (doc/shovill_half_out)
shovill --outdir doc/shovill_half_out --R1 data/R1.half.fastq --R2 data/R2.half.fastq --cpus 4

# 2차 시도: 유전체 크기를 원본 추정값으로 고정 (doc/shovill_half_gsize_out)
shovill --outdir doc/shovill_half_gsize_out --R1 data/R1.half.fastq --R2 data/R2.half.fastq \
        --gsize 61920 --cpus 4
```

- 6,248 쌍이 뽑혔다(원본 12,480 쌍의 50.06%). R1/R2 read 이름 순서가 일치하는 것을 확인했다.
- **1차 시도는 실패했다.** shovill은 "11번 이상 등장한 21-mer"의 개수로 유전체 크기를 추정한다.
  read가 절반이 되자 많은 k-mer가 10번 이하로 떨어져 유전체 크기를 4,551 bp(커버리지 411x)로 잘못 추정했고,
  SPAdes가 "Invalid kmer coverage histogram" 오류를 내며 contig를 하나도 만들지 못했다.
  커버리지가 낮아지면 조립뿐 아니라 그 앞 단계(유전체 크기 추정)도 흔들린다는 것을 보여준다.
- 공정하게 비교하려고 2차 시도에서는 `--gsize 61920` 으로 원본과 같은 유전체 크기를 지정했다.

## 3. 결과

| | 원본 (100%) | 절반 (50%) |
|---|---|---|
| read 쌍 | 12,480 | 6,248 |
| 커버리지 (shovill 추정) | 60x | 30x |
| contig 수 | 12 | 8 |
| 전체 길이 (bp) | 180,912 | 174,465 |
| 가장 긴 contig (bp) | 73,132 | 54,645 |
| **N50 (bp)** | **58,878** | **54,544** (약 7% 감소) |

contig 길이 (긴 순서):
- 원본: 73132 58878 35158 5981 3843 1046 816 790 645 223 203 197
- 절반: 54645 54544 34937 15902 5981 4778 2888 790

## 4. 결론

- **예상대로 커버리지를 줄이자 N50이 줄었다** (58,878 → 54,544 bp). 가장 긴 contig(73 kb)는
  더 이상 한 조각으로 이어지지 못하고 54.6 kb와 15.9 kb 정도로 나뉜 것으로 보인다.
- 감소 폭은 약 7%로 크지 않았다. "커버리지가 충분하면 절반으로 줄여도 N50이 크게 무너지지 않는다"는 예상과 맞다.
- 예상과 다른 점: contig 수는 오히려 12개에서 8개로 **줄었다**. 원본에 있던 1 kb 이하의 작은 contig들
  (223, 203, 197 bp 등)이 절반 데이터에서는 만들어지지 않았기 때문이다. 대신 전체 길이가 약 6.4 kb 줄었다.
  즉 커버리지가 낮아지면 "잘게 쪼개짐"뿐 아니라 "일부 구간이 아예 조립되지 않음"도 일어난다.
  그래서 contig 수만 보면 조립이 좋아진 것처럼 보일 수 있으므로, N50·전체 길이를 함께 봐야 한다.
- 참고: 조립된 전체 길이(약 181 kb)가 shovill의 유전체 크기 추정값(61,920 bp)보다 훨씬 크다.
  유전체가 실제로 약 181 kb라면 실제 커버리지는 3,744,000 ÷ 180,912 ≈ **21x**, 절반 데이터는 약 **10x**이다.
  SPAdes 로그의 k-mer 중앙 커버리지(16)도 약 20x read 커버리지와 맞는다. 따라서 "60x → 30x"는
  shovill 추정값 기준이고, 실제로는 "약 20x → 10x" 실험이었을 가능성이 높다.
