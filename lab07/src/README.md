# FASTA 도구 상자

`fasta.py`는 생물정보학에서 사용하는 DNA 염기서열을 읽고, 분석하고, 저장하기 위해 만든 Python 함수 모음이다. 다른 Python 프로그램에서 함수를 불러와 사용하면 같은 코드를 반복해서 작성하지 않아도 된다.

## 1. `read_fasta(filename)`

- **입력:** 읽을 FASTA 파일의 경로 또는 파일 이름
- **반환:** 서열 이름을 키로, 염기서열을 값으로 저장한 딕셔너리
- **사용 예:** `seqs = read_fasta("data/seqs.fasta")`

FASTA 파일에서 서열 이름과 염기서열을 읽어 딕셔너리로 정리한다. 파일에 있는 염기서열은 대문자로 변환하여 저장한다.

## 2. `gc_content(seq)`

- **입력:** DNA 염기서열 문자열
- **반환:** 전체 염기 중 G와 C가 차지하는 비율을 0과 1 사이의 숫자로 반환한다. 빈 문자열을 입력하면 `0.0`을 반환한다.
- **사용 예:** `gc_content("ATGC")`

염기서열에서 G와 C의 개수를 세고 전체 길이로 나누어 GC 비율을 계산한다. GC 비율을 이용하면 서열의 염기 구성 특성을 확인할 수 있다.

## 3. `reverse_complement(seq)`

- **입력:** DNA 염기서열 문자열
- **반환:** 입력 서열의 역상보 서열
- **사용 예:** `reverse_complement("ATGC")`

A는 T로, T는 A로, G는 C로, C는 G로 바꾼 다음 서열의 순서를 뒤집는다. DNA의 반대 가닥에 해당하는 서열을 구할 때 사용한다.

## 4. `write_fasta(seqs, filename)`

- **입력:** 서열 이름과 염기서열을 저장한 딕셔너리, 저장할 파일 이름
- **반환:** 별도의 반환값은 없다. 결과를 FASTA 파일로 저장한다.
- **사용 예:** `write_fasta(seqs, "result.fasta")`

딕셔너리에 저장된 서열 이름 앞에 `>`를 붙이고, 다음 줄에 염기서열을 기록하여 FASTA 형식의 파일을 만든다.

## 5. `length_stats(seqs)`

- **입력:** 서열 이름과 염기서열을 저장한 딕셔너리
- **반환:** 서열 개수(`count`), 전체 길이(`total`), 평균 길이(`mean`), 가장 짧은 서열의 길이(`min`), 가장 긴 서열의 길이(`max`)가 담긴 딕셔너리
- **사용 예:** `stats = length_stats(seqs)`

여러 염기서열의 길이를 계산하여 전체적인 길이 통계를 한 번에 확인할 수 있다. 서열이 하나도 없는 경우에는 모든 통계값을 0으로 반환한다.

## 6. 부족한 점과 추가하고 싶은 기능

현재 도구 상자는 FASTA 파일 읽기와 저장, GC 비율 계산, 역상보 서열 생성, 서열 길이 통계 계산 기능을 갖추고 있다. 하지만 잘못된 FASTA 파일 형식이나 A, T, G, C 이외의 문자가 입력되었을 때 오류를 처리하는 기능은 아직 부족하다. 앞으로는 입력된 서열이 올바른 DNA 염기서열인지 검사하는 함수와 특정 조건에 맞는 서열만 골라내는 필터링 함수를 추가하고 싶다. 이러한 기능을 추가하면 여러 FASTA 파일을 더 안전하고 효율적으로 분석할 수 있을 것이다.
